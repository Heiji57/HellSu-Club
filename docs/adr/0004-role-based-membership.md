# ADR-0004: Discord 역할을 회원·관리자 권한의 유일한 기준으로 쓴다

- 상태: 승인
- 날짜: 2026-11-04

## 맥락
v1은 `/회원등록` 명령과 DB의 `role` 컬럼, Discord 역할을 함께 검증하려 했다. 하지만 두 기준이 어긋나면 어느 쪽이 맞는지 알 수 없고, 첫 관리자를 지정하는 방법도 없었다.

## 결정
- `MEMBER_ROLE_ID` 보유자가 회원, `ADMIN_ROLE_ID` 보유자가 관리자다.
- `member` 테이블은 기록과 집계를 위한 것이며 권한 컬럼을 두지 않는다.
- 역할 부여 시 등록·재활성화하고, 역할 회수나 서버 탈퇴 시 비활성화한다.
  - 처리 경로: `on_member_update`, `on_member_remove`, 봇 시작 시 전체 동기화
- Server Members Intent를 사용한다.
- 관리자 명령은 실행할 때마다 interaction의 역할 목록으로 권한을 확인한다.

## 결과
- `/회원등록`, `/회원비활성화` 명령이 없어진다.
- 첫 관리자 지정은 Discord에서 역할을 주는 것으로 끝난다.
- AuditLog의 행위자는 `member` FK 대신 `actor_discord_id`로 기록한다. 관리자가 회원 역할이 없을 수도 있기 때문이다.
