# ADR-0005: 결과 알림은 ephemeral 메시지로, 늦게 결정된 결과는 다음 명령 때 전달한다

- 상태: 승인
- 날짜: 2026-11-04

## 맥락
운영자는 인증 결과를 본인과 관리자만 보게 하고, DM 대신 채널에서 본인에게만 보이는 메시지로 보내기로 정했다. 그런데 ephemeral 메시지는 interaction 토큰이 유효한 15분 안에만 보낼 수 있다. 관리자 검토 결과는 그 이후에 나온다.

## 결정
- 규칙 판정 결과는 `/인증` 응답에 바로 담는다(동기 처리).
- 관리자 승인·거절·출석 취소 결과는 `result_notified_at IS NULL`로 남겨 둔다. 그 회원이 다음에 아무 명령이나 쓰면 ephemeral followup으로 전달하고 시각을 기록한다.
- `/내기록`은 항상 최신 상태와 사유를 보여준다.

## 결과
- 회원이 봇을 다시 쓰기 전까지는 검토 결과를 알 수 없다. 30명 규모이고 검토는 드물어서 받아들일 수 있다.
- 관리자 검토 요청은 관리자 전용 채널에 일반 메시지로 게시한다. 관리자 채널이므로 공개 범위 정책에 어긋나지 않는다.
