# ADR-0002: AI 검증 제외, 규칙 기반 자동 승인과 관리자 사후 검토

- 상태: 승인
- 날짜: 2026-11-04

## 맥락
명세 v1은 Vision LLM으로 인증을 판정하려 했다. 하지만 다음과 같은 문제가 있었다.
- 30명 규모의 동호회는 사실상 서로 믿고 운영되는 구조다.
- AI는 촬영 시각이나 본인 여부를 증명할 수 없다.
- 비용, API 키 관리, 회원 사진을 외부로 전송하는 개인정보 문제가 생긴다.
- 운영자가 AI를 쓰지 않기로 결정했다.

## 결정
- 입력 검증과 이미지 중복 탐지(SHA-256, pHash)를 통과하면 즉시 자동 승인한다.
- 중복이 의심되면 관리자 검토로 보낸다.
- 부적절한 인증은 관리자가 사후에 출석을 취소한다.
- 그 결과 v1의 다음 요소를 제거한다.
  - `app/ai`
  - `BackgroundJob` 테이블과 Worker: 판정이 동기식이라 비동기 작업 큐가 필요 없다.
  - APScheduler: 주기 작업 두 개는 `discord.ext.tasks`로 충분하다.
  - `verification_review.reviewer_type`의 `AI`
  - 인증 상태의 `RECEIVED`, `PROCESSING`, `FAILED`

## 확장 지점
나중에 AI가 필요해지면 다음 순서로 추가한다.
1. `VerificationService`의 판정 단계에 판정기를 추가한다.
2. 인증 상태 `PENDING_ANALYSIS`, 작업 테이블, Worker를 추가한다.
3. `verification_review`에 `reviewer_type='AI'`와 모델·프롬프트 버전 컬럼을 추가한다.

## 결과
- 텍스트만 있는 인증은 최소 글자 수만 확인하므로 사실상 자기 신고다.
- 무관한 사진은 자동으로 걸러지지 않는다. 운영 중 문제가 커지면 이 ADR을 다시 검토한다.
