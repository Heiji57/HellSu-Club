# ADR-0003: 출석일은 제출 시각(KST)의 날짜로 정하고 인증에 저장한다

- 상태: 승인
- 날짜: 2026-11-04

## 맥락
v1에서는 출석일이 정의되지 않았고, 승인할 때 출석이 생성됐다. 그래서 일요일에 낸 인증을 관리자가 월요일에 승인하면 다음 주 출석으로 집계될 수 있었다. 운영자는 "인증을 올린 요일 기준"으로 정했다. 자정을 넘긴 운동에 유예 시간은 두지 않는다.

## 결정
- `verification.workout_date = (interaction.created_at을 Asia/Seoul로 변환).date()`
- INSERT할 때 계산해서 저장하고 이후 변경하지 않는다.
- 출석은 승인 시점과 관계없이 이 값을 쓴다.
- 기준 시각은 서버의 처리 시각이 아니라 Discord interaction 생성 시각이다.

## 결과
- 주 경계에서 처리가 지연되거나 관리자 검토가 늦어져도 집계 주가 바뀌지 않는다.
- 23:50에 시작해 00:30에 끝낸 운동을 00:30에 인증하면 다음 날 출석이 된다(운영 정책).
