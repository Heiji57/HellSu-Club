# ADR-0001: 단일 프로세스 Discord 봇

- 상태: 승인
- 날짜: 2026-11-04

## 맥락
회원은 10~30명이고 Discord 서버는 하나다. 명세 v1도 FastAPI, Redis, 메시지 브로커, 프론트엔드를 쓰지 않기로 했다.

## 결정
discord.py 프로세스 하나가 명령 처리, 주기 작업, DB 접근을 모두 맡는다. 내부는 `bot/`(Discord 표현)과 `app/`(비즈니스 로직, 데이터)로 나눈다. 서비스는 Discord 타입에 의존하지 않는다.

## 결과
- 배포 단위는 `bot`과 `db` 컨테이너 두 개뿐이다.
- 수평 확장은 고려하지 않는다. 필요해지면 `app/`을 그대로 둔 채 진입점만 추가할 수 있다.
